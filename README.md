# ระบบคลังสินค้าร้านแว่นตา พร้อม MySQL

ระบบนี้เป็นเว็บแอปสำหรับจัดการสต็อกร้านแว่นตา มีแดชบอร์ด, POS ขายหน้าร้าน, การแจ้งเตือนสต็อกต่ำ และฐานข้อมูล MySQL

## ฟีเจอร์หลัก
- เพิ่มสินค้าใหม่
- รับสินค้าเข้าและขายสินค้าออก
- ระบบ POS สำหรับการขายหน้าร้าน
- ตั้งค่าการแจ้งเตือนสต็อกต่ำ
- ดูรายการสินค้าที่ใกล้หมด
- เชื่อมฐานข้อมูล MySQL จริง

## วิธีติดตั้ง
1. เปิด terminal ไปที่โฟลเดอร์ `c:\Users\bank1\OneDrive\Desktop\index`
2. รัน `npm install`
3. สร้างไฟล์ `.env` โดยคัดลอกจาก `.env.example` และแก้ค่าให้ตรงกับ MySQL ของคุณ
4. สร้างฐานข้อมูลด้วย `db.sql` หรือให้ `server.js` สร้างให้เอง

## ตัวอย่าง `.env`
```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=eyewear_inventory
PORT=3000
```

## รันระบบ
- รัน `npm start`
- เปิดเว็บเบราว์เซอร์ไปที่ `http://localhost:3000`

## หมายเหตุ
- หากยังไม่มีฐานข้อมูล MySQL ให้ติดตั้ง MySQL/MariaDB ก่อน
- ถ้าต้องการรีเซ็ตตาราง ให้ลบฐานข้อมูล `eyewear_inventory` แล้วรันใหม่
